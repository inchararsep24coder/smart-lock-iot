# Smart Lock System Using IoT

An IoT-based smart lock system concept designed to provide secure, convenient access using connected devices.

## Project Overview

The system is designed to replace traditional physical keys with smartphone-controlled access and connected lock monitoring.

## Key Features

- Smartphone-controlled access
- App-based unlocking
- Live door status monitoring
- Access alerts and notifications
- IoT microcontroller
- Wi-Fi/BLE connectivity
- Relay-based lock control
- Mobile dashboard concept

## Technologies and Components

- IoT
- Microcontroller
- Wi-Fi/BLE
- Relay actuator
- Mobile application/dashboard

## Project Status

Concept and prototype stage.
